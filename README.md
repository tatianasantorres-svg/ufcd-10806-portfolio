#  Portefólio de Trabalhos Práticos — UFCD 10806

Este repositório reúne o conjunto de exercícios, guiões e scripts práticos desenvolvidos ao longo da Unidade de Formação de Curta Duração **UFCD 10806 – Linguagens de Scripting e Linha de Comandos**, integrada no meu percurso de especialização em Gestão de Informação e Ciência de Dados.

O objetivo deste portefólio foi consolidar os conceitos fundamentais de automação de tarefas, administração de sistemas e manipulação de ficheiros através da linha de comandos.

---

##  Ferramentas e Tecnologias
* **Linguagem de Scripting:** Windows PowerShell
* **Ambiente de Desenvolvimento:** Visual Studio (VS Code)
* **Conceitos Práticos:** Estruturas de decisão (`if/else`), ciclos (`foreach`), variáveis de ambiente, manipulação de ficheiros/diretórios e automação via terminal.

---

##  O que este portefólio demonstra?
* **Lógica de Automação:** Resolução passo a passo de problemas práticos focados na eficiência e gestão de processos no sistema operativo.
* **Competência em Linha de Comandos:** Domínio dos comandos e utilitários nativos para interação com o sistema sem necessidade de interface gráfica.
* **Organização de Código:** Scripts estruturados no Visual Studio para garantir uma execução limpa e documentada.

---

## Como navegar neste repositório?
Os ficheiros de script (extensão `.ps1`) estão organizados por guiões de aula ou módulos temáticos. Pode abrir qualquer um deles diretamente acima para verificar a lógica aplicada.
